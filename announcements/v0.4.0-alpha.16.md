# reinhardt-web v0.4.0-alpha.16

## Highlights

This release focuses heavily on tying generated forms directly into the mutation and data layers that back them. `ModelForm` and named `ClientForm` DTOs can now render through `action.page()` using the exact runtime already attached to a configured mutation (#6301, #6302), so controls, validation, pending state, and callbacks share a single submission lifecycle instead of being composed separately. Building on this, a new opt-in bridge lets validated model-form update payloads apply as typed partial writes against an already-scoped `QuerySet` (#6340), so edit forms can safely submit only the fields they own without overwriting unrelated data from a stale snapshot.

Routing gains a new argumentless `#[url_patterns]` mode that lets a single `UnifiedRouter` declaration reference cfg-gated native handlers: browser/WASM builds erase the server-only arguments before name resolution, while native server builds keep the real handlers registered (#6303).

Static asset handling is significantly reworked with a unified, manifest-driven publication pipeline for both Pages build output (JS/WASM/CSS) and collected static files, including a new `buildstatic` command, deterministic versioned manifests, reference rewriting, and stricter file-response handling so missing assets can't silently fall back to SPA HTML (#6347).

On the realtime side, Pages now exposes owned, typed WebSocket event subscriptions that can drive typed `QueryClient` invalidation directly from connection status changes (#6343), and the WebSocket reconnect/retry lifecycle from the mainline fix is forward-ported to this branch with deterministic browser-tested teardown and resubscription behavior (#6352).

The remainder of the release is a large batch of routing/macro alias-tracking hardening (nested, aliased, and control-flow URL router bindings), plus numerous CI and dependency-policy repairs (AWS Smithy baselines, `rand` 0.10, `synstructure`, `evcxr`/Unicode constraints) that keep the release pipeline and prerelease baselines building reliably.

## Breaking Changes

No breaking changes in this release.
