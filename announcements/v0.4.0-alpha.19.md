# reinhardt-web v0.4.0-alpha.19

## Highlights

This release lands a significant set of ORM correctness fixes alongside several breaking changes on the `develop/0.4.0` line.

**Database execution correctness:** Native query execution previously widened `i32` parameters to `i64`, causing PostgreSQL functions expecting `integer` (e.g., `right(text, integer)`) to fail with a type mismatch. `QueryValue` now preserves 32-bit parameters via a new `Int32` variant, while `i64` values continue to bind as `bigint`.

**Composite primary key improvements:** Updates to models with composite keys (e.g., `(tenant, entry)`) now correctly match every key component instead of only the first, preventing accidental overwrites of unrelated rows that shared a partial key. Generated composite keys also gain support for UUID and `ModelEnum` fields by encoding components through the shared `DatabaseField` codec, preserving native types and avoiding brittle ad hoc `Display`/`PkValue` conversions.

**Migrations:** Expression and partial indexes with differing predicates or expressions no longer collide on generated names — a deterministic hash suffix now disambiguates them while model-declared partial indexes keep their explicit names. The strict migration parser now accepts `.into()` and `.to_owned()` string conversions in manually edited migration files, matching existing `.to_string()` support.

**Other fixes:** `select_related` joins now declare the correct table alias, fixing a SQLite failure; `migrate --fake` initializes migration history correctly on a fresh database; generated REST scaffolds now seed the `contacts` settings fragment so generated projects resolve their configuration out of the box; and `makemigrations` now scopes detection to configured application labels while preserving physical table identity across model moves.

A broad test-audit cleanup (#6459) repairs ten confirmed cases where suites previously passed without exercising their intended behavior, restoring real regression coverage across ORM, migrations, admin auditing, SMTP, and HTTP composition.
