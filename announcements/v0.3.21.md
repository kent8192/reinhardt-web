# reinhardt-web v0.3.21

## Highlights

This release is a broad bug-fix pass across the migration system, SQL generation, and ORM layer, consolidating several stabilization backports onto the `0.3.x` line.

Migration reliability improves significantly: `makemigrations` and `migrate` now correctly scope operations to installed apps (including a backported capability-aware entry point), honor custom `--migration-dir` paths, and preserve rollback ordering across app boundaries so dependent migrations in other apps are reversed before their prerequisites. Composite primary keys now honor `db_column` aliases in generated predicates and updates, migration replay preserves unchanged physical table identity instead of misdetecting renames, and PostgreSQL recorder advisory locks are released within the same transaction, preventing one migrator from blocking another.

A large set of SQL-generation fixes corrects cross-backend correctness bugs: PostgreSQL expression and custom-predicate grouping is preserved so OR/AND compositions evaluate as intended; raw bind markers and quoted identifiers survive parameter inlining; byte values render as typed `bytea`; `ON CONFLICT` clauses correctly omit empty targets, support SQLite's targetless upserts, and reject unsupported MySQL configurations instead of silently dropping them; arithmetic and CASE expressions keep correct grouping on MySQL and SQLite; and case-insensitive and range filters now work correctly on MySQL and SQLite through properly quoted, backend-aware rendering.

The ORM also gains more precise native value binding — avoiding precision loss for large integers, decimals, and typed arrays — fixes MySQL bulk creation to avoid unsupported `RETURNING` clauses, and corrects `EXISTS` and `Session` read decoding across backends. Native HTTP endpoints can now serve streaming (e.g. SSE) responses end-to-end, test fixtures properly cancel in-flight connections on shutdown, and the facade correctly forwards UUID support to DI for path extraction.

## Breaking Changes

No breaking changes in this release.
