# reinhardt-web v0.3.15

## Highlights

This release focuses primarily on security hardening and stability fixes across the dentdelion plugin system. Several related fixes confine plugin loading to its declared root directory, close a path resolution race condition, and restore the anchored loader behavior that some plugins depend on — together these changes prevent plugins from escaping their intended filesystem scope while preserving expected loading semantics for well-behaved plugins.

The middleware layer also receives a security fix that prevents private cache responses from being replayed to unintended requesters, reducing the risk of sensitive data leaking through shared caches.

On the admin side, a previous advisory fix is merged forward to ensure it applies cleanly against the latest `main`, and new tests verify that ModelAdmins granting permissions via empty object filters behave correctly — improving confidence in the permission-checking logic for admin views.

Finally, a small but important fix in the utils crate gates an async filesystem import so it's only pulled in when actually needed, and removes an unused filesystem import that was tripping up native test builds. This keeps builds leaner and avoids unnecessary platform-specific dependencies in environments that don't need async filesystem access.
